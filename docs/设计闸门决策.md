# KidTimeline 设计闸门决策

**日期**：2026-08-28  
**PRD 版本**：v4 终稿  
**技术可行性闸门**：已通过（修订版，对齐 Tot Clock 底座）

---

## 设计级别选择

| 选项 | 内容 | 适用场景 |
|------|------|----------|
| **① 交互 + UI**（推荐） | 做交互设计 + UI 视觉设计 | 涉及新界面，推荐 |
| ② 仅交互 | 只做交互规格，不做视觉 | 功能逻辑为主 |
| ③ 跳过设计 | 直接进入开发 | 已有设计稿或极简项目 |

### 决策理由

选择 **① 交互 + UI**，理由：

1. **时间轴视图是全新的**：Tot Clock 是圆钟，我们需要线性时间轴 + 睡觉弧，没有现成参考
2. **学龄前儿童界面**：颜色、图标、交互都需要专门设计，不能套用成人 UI
3. **三态渲染复杂**：已过去/当前/未来的视觉区分需要明确规范
4. **家长面板交互**：拖拽、吸附、必须/自由切换等交互细节需要定义

## 设计资产清单

### 交互设计

| 资产 | 说明 |
|------|------|
| 主界面交互流程 | 时间轴视图的三种状态（白天/临近/睡觉） |
| 家长面板交互 | 拖拽排序、时间修改、节点增删 |
| 提醒交互 | 蜂鸣时机、开关控制 |
| 多设备同步交互 | 配置更新提示 |

### UI 设计

| 资产 | 说明 |
|------|------|
| 颜色系统 | 6种类别色 + 三态色 |
| 图标系统 | 18个 emoji + 3个补加 |
| 节点样式 | 必须做（实线）vs 自由（虚线） |
| 时间轴样式 | 黄色直条 + 蓝色弧线 |
| 家长面板样式 | 布局、按钮、输入框 |

---

## 设计评审标准

| 维度 | 标准 |
|------|------|
| **可读性** | 学龄前儿童能看懂（不依赖识字） |
| **对比度** | WCAG AA 标准（≥ 4.5:1） |
| **一致性** | 颜色编码统一（类别色 + 状态色） |
| **响应式** | 桌面/平板/手机适配 |
| **可访问性** | 支持 prefers-reduced-motion |

---

**决策**：选择 ① 交互 + UI
