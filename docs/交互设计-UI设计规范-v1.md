# KidTimeline 交互设计 & UI 设计规范

**版本**：v1.0  
**日期**：2026-08-28  
**设计风格**：参考 Tot Clock，大色块、高对比、适配学龄前儿童

---

## 一、核心设计原则

| 原则 | 说明 |
|------|------|
| **大色块** | 每个活动用独立色块，不依赖文字识别 |
| **高对比** | 边框 2-3px，图标 ≥48px，颜色饱和度高 |
| **不识字友好** | 用图标 + 颜色区分，不依赖文字阅读能力 |
| **防误触** | 家长设置入口隐藏（长按 2 秒），孩子无法误进 |
| **视觉节奏** | 必须做的事=实线粗框，自由=虚线框，形成视觉节奏 |

## 二、主界面：时间轴视图

### 2.1 布局结构

```
┌─────────────────────────────────────────┐
│  ⚙️ (半透明齿轮，长按进入家长面板)      │
│                                         │
│           当前时间（大号）              │
│                                         │
│  ┌─────────────────────────────────┐   │
│  │  时间轴直条（黄色区域）         │   │
│  │  [起床][早饭][玩耍][午饭]...[睡觉] │   │
│  │  ↑ 游标箭头                      │   │
│  └─────────────────────────────────┘   │
│                                         │
│     7:30              12:00     20:30   │
│                                         │
│    【还有 X 小时 Y 分钟】              │
│                                         │
│    下一个：🍽️ 午饭（12:00）           │
└─────────────────────────────────────────┘
```

### 2.2 三种状态

#### 状态 1：白天模式（正常）

- **背景色**：`#FFFEF7`（米白）
- **时间轴**：黄色区域（`#FAC775`），节点按类别着色
- **游标**：橙色箭头（`#BA7517`），指向当前活动
- **剩余时间**：常规显示（`还有 X 小时 Y 分钟`）
- **视觉强度**：低，正常氛围

#### 状态 2：临近睡觉（最后阶段）

- **触发条件**：距睡觉 ≤ 10 分钟
- **背景色**：`#F0F4FF`（淡蓝，冷色调提示）
- **当前节点**：红色脉冲动画（`#F09595`，`animation: pulse 2s infinite`）
- **剩余时间**：大字红橙（`还有最后 X 分钟`，字号 1.6 倍）
- **视觉强度**：高，紧迫感

#### 状态 3：睡觉模式（夜间）

- **触发条件**：当前时间在睡觉区间内
- **背景色**：`#1A1A2E`（深蓝黑）
- **时间轴**：蓝色弧（`#85B7EB`），从右端（入睡）绕回左端（起床）
- **图标**：月亮 🌙 + 星星 ✨ 装饰
- **剩余时间**：`还能睡 X 小时 Y 分钟`（蓝色冷调）
- **视觉强度**：低，安静氛围

### 2.3 节点视觉规范

| 节点类型 | 边框样式 | 边框粗细 | 颜色示例 |
|---------|---------|---------|---------|
| **必须做的事** | 实线 | 2-3px | 橙 `#BA7517` / 青 `#0F6E56` / 蓝 `#185FA5` |
| **自由时间** | 虚线 | 2px | 绿 `#3B6D11` |

**节点尺寸**：
- 当前节点：60×70px（高亮）
- 未来节点：50×50px（正常）
- 过去节点：50×50px（去饱和 + 半透明）

**图标尺寸**：
- 当前节点：32px
- 未来节点：24px
- 过去节点：24px + opacity 0.5

### 2.4 自适应精度显示

| 剩余时间 | 显示文案 | 字号 | 颜色 | 动画 |
|---------|---------|------|------|------|
| > 2 小时 | `还有 X 小时` | 18px | 常规 | 无 |
| 30分~2小时 | `还有 X 小时 Y 分` | 18px | 常规 | 无 |
| 10~30 分 | `还有 X 分钟` | 20px | 暖橙 | 轻微放大 |
| ≤ 10 分钟 | `还有最后 X 分钟` | 24px | 红橙 | 脉冲 |
| ≤ 5 分钟 | `还有最后 X 分钟` | 28px | 强红 | 强脉冲 |
| ≤ 1 分钟 | `还有 X 秒` | 32px | 红 | 逐秒跳动 |

### 2.5 游标交互

- **位置**：始终指向当前活动节点顶部
- **形状**：向下箭头（三角形）
- **颜色**：随状态变化（白天橙 / 临近红 / 夜间蓝）
- **动画**：每秒轻微呼吸（`scale 1 → 1.05 → 1`）

## 三、家长面板：设置界面

### 3.1 入口

- **位置**：主界面左上角
- **视觉**：齿轮图标 ⚙️，透明度 20%（微弱引导）
- **交互**：长按 2 秒 → 震动反馈 → 弹出面板
- **防误触**：孩子不会注意，家长知道位置

### 3.2 面板布局

```
┌─────────────────────────────────────────┐
│  ⚙️ 家长设置                        ✕  │
│  ─────────────────────────────────────  │
│                                         │
│  🕐 作息时间                            │
│  ┌─────────────┬─────────────┐         │
│  │ 起床时间    │ 睡觉时间    │         │
│  │ [07:30]     │ [20:30]     │         │
│  └─────────────┴─────────────┘         │
│                                         │
│  📋 活动节点（拖拽排序）  [+ 添加节点] │
│  ┌──────────────────────────────────┐  │
│  │ ⋮⋮ 🛏️ 起床  [07:30]    [必须]  │  │
│  │ ⋮⋮ 🍽️ 早饭  [08:00]    [必须]  │  │
│  │ ⋮⋮ 🧸 玩耍  [09:00]    [自由]  │  │
│  │ ⋮⋮ 🍽️ 午饭  [12:00]    [必须]  │  │
│  │ ⋮⋮ 📚 绘本  [13:00]    [自由]  │  │
│  │ ⋮⋮ 🦷 刷牙  [20:00]    [必须]  │  │
│  │ ⋮⋮ 🌙 睡觉  [20:30]    [必须]  │  │
│  └──────────────────────────────────┘  │
│                                         │
│  🔔 提醒设置                            │
│  蜂鸣提醒           [开关 ○]           │
│  提前提醒（分钟）   [5]                │
│                                         │
│  📱 多设备同步                          │
│  访问口令           [设置口令]         │
│  当前状态：未设置                       │
│                                         │
│  ─────────────────────────────────────  │
│  [重置默认]        [保存配置]           │
└─────────────────────────────────────────┘
```

### 3.3 节点编辑交互

#### 拖拽排序

- **触发**：按住节点左侧 `⋮⋮` 图标
- **反馈**：节点半透明（opacity 0.7），显示临时位置线
- **松手**：自动保存，节点高亮闪烁确认
- **冲突**：两个节点时间重叠时，自动重排并短暂高亮冲突节点

#### 修改时间

- **触发**：点击节点内的时间输入框
- **控件**：原生 `<input type="time">`
- **保存**：失焦后自动保存，无需手动点"保存"

#### 添加节点

- **触发**：点击 `+ 添加节点` 按钮
- **流程**：
  1. 弹出选择图标面板（18 个预设 emoji）
  2. 输入活动名称（可选，默认用图标名）
  3. 设置时间
  4. 选择"必须"或"自由"
  5. 确认添加

#### 删除节点

- **触发**：左滑节点（移动端）或长按后选择"删除"（桌面端）
- **确认**：弹出确认对话框（防误删）
- **恢复**：删除后 5 秒内可撤销（底部 toast）

### 3.4 必须/自由切换

- **触发**：点击节点右侧的 `[必须]` / `[自由]` 标签
- **切换**：点击即切换，实线 ↔ 虚线，颜色同步变化
- **反馈**：标签颜色变化（必须=深橙/深青，自由=绿色）

## 六、交互动画

### 6.1 节点动画

| 动画 | 触发条件 | 效果 | 时长 |
|------|---------|------|------|
| 呼吸 | 当前节点 | `scale 1 → 1.05 → 1` | 2s infinite |
| 脉冲 | 临近睡觉（≤10min） | `scale 1 → 1.1 → 1` | 1s infinite |
| 高亮闪烁 | 拖拽松手后 | `opacity 0.5 → 1` | 0.3s |
| 去饱和 | 已过去节点 | `opacity 0.5 + grayscale` | 持续 |

### 6.2 游标动画

| 动画 | 触发条件 | 效果 | 时长 |
|------|---------|------|------|
| 呼吸 | 每秒 | `scale 1 → 1.05 → 1` | 1s infinite |
| 移动 | 时间变化 | `transform: translateX` 平滑过渡 | 0.5s ease |

### 6.3 模式切换动画

| 动画 | 触发条件 | 效果 | 时长 |
|------|---------|------|------|
| 淡入淡出 | 进入临近模式 | 背景色渐变 | 1s |
| 淡入淡出 | 进入睡觉模式 | 背景色渐变 + 时间轴变形 | 2s |

## 七、响应式适配

### 7.1 桌面端（≥1024px）

- 时间轴宽度：80% 屏幕宽度
- 节点尺寸：标准（60×70px）
- 家长面板：居中弹窗，宽度 500px

### 7.2 平板端（768px~1023px）

- 时间轴宽度：90% 屏幕宽度
- 节点尺寸：标准（60×70px）
- 家长面板：全屏弹窗

### 7.3 手机端（<768px）

- 时间轴宽度：95% 屏幕宽度
- 节点尺寸：缩小（50×60px）
- 家长面板：全屏弹窗
- 拖拽交互：左滑删除替代长按

## 八、无障碍设计

| 要素 | 设计 |
|------|------|
| **颜色对比** | 文字与背景对比度 ≥ 4.5:1（WCAG AA） |
| **图标大小** | 最小 24px，便于低视力用户 |
| **边框粗细** | 2-3px，清晰可辨 |
| **动画减弱** | 支持 `prefers-reduced-motion`，禁用动画 |
| **键盘导航** | 家长面板支持 Tab 键导航 |
