## 一、项目概述

### 项目目标

为学龄前儿童（2-5岁）开发一款时间可视化时钟，帮助孩子直观感受"时间流逝"和"一天作息"。

### 核心需求

1. **线性时间轴**：黄色直条表示白天，蓝色弧线表示睡觉（跨夜闭环）
2. **节点可视化**：每个活动是一个节点，图标 + 颜色，不依赖识字
3. **三态渲染**：已过去（灰色）/ 当前（高亮）/ 未来（原色）
4. **自适应精度**：最后 10 分钟大字红橙提示
5. **家长面板**：隐藏入口（长按左上角 2 秒），可调整作息、拖拽排序
6. **蜂鸣提醒**：节点到达时"嘀嘀嘀"响，可关闭
7. **多设备同步**：局域网内手机改配置，平板实时同步

### 不做清单（v1）

- ❌ iOS App（需要 Mac + Xcode，成本过高）
- ❌ 微信小程序（低优先级，需重写前端）
- ❌ 语音播报（TTS，改用 Web Audio 蜂鸣）
- ❌ 登录账号体系（走局域网同步，可选访问口令）
- ❌ 云端存储（数据不出局域网）

## 二、底座项目：Tot Clock

### 项目信息

- **仓库**：https://github.com/basnijholt/tot-clock
- **版本**：v1.0.0
- **技术栈**：Svelte 5.43.8 + Vite 7.2.4 + TypeScript 5.9.3
- **运行时**：Bun（需改写为 Node）
- **许可证**：MIT（可自由改造）

### 已验证的技术点

1. **时间漂移补偿**（`timer.ts:86-95`）：页面后台返回后时间计算准确
2. **三层持久化**（`timer.ts:142-172`）：localStorage + debounce + 服务端
3. **Wake Lock**（`App.svelte:76-79`）：屏幕常亮，适合挂墙平板
4. **防误触长按**（`App.svelte:31-44`）：长按 2 秒进家长面板
5. **拖拽排序**（`ParentPanel.svelte`）：`setPointerCapture` 手势流畅
6. **活动图标系统**（`activities.ts`）：18 个 emoji + 颜色
7. **服务端同步**（`server.ts`）：`/api/state` + `/api/settings`

### 需要改写的部分

1. **server.ts**：Bun → Node（约 85 行代码，保持 API 不变）
2. **圆钟视图**：Tot Clock 是圆钟，我们要线性时间轴（需重写）
3. **倒计时模型**：Tot Clock 是顺序倒计时，我们要挂钟模型（需新建）
4. **英文 UI**：Tot Clock 是英文，我们要中文（需翻译）

### 第二阶段：挂钟模型（1天）

**目标**：新建 `timeline.ts`，实现挂钟模型 + 跨夜处理

**任务**：
1. 定义数据结构：
   ```typescript
   interface TimelineNode {
     id: string;
     activity: Activity;
     startTime: string; // "07:30"
     endTime: string;   // "08:00"
     required: boolean; // 必须做 vs 自由
   }
   
   interface TimelineConfig {
     wakeTime: string;    // "07:30"
     sleepTime: string;   // "20:30"
     nodes: TimelineNode[];
     updatedAt: number;   // 时间戳
   }
   ```
2. 实现核心函数：
   - `getCurrentNode(nodes, currentTime)` → 返回当前活动节点
   - `getProgress(node, currentTime)` → 返回 0~1 进度
   - `getRemainingTime(node, currentTime)` → 返回剩余秒数
   - `isCrossNight(sleepTime, wakeTime)` → 判断是否跨夜
3. 编写单元测试（覆盖跨夜场景）

**验收标准**：
- ✅ 单元测试全部通过
- ✅ 跨夜场景正确（20:30 → 07:00）
- ✅ 当前节点判定正确

## 八、已知限制

1. **后台定时器**：Android Chrome 节流，但挂墙场景页面始终在前台，影响不大
2. **PWA 安装**：iOS 需手动"添加到主屏幕"，Android 自动提示
3. **跨时区**：时间轴基于设备本地时间，时区变化后自动重新计算
