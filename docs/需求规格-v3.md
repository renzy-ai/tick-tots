## 1. 核心概念模型

| 术语 | 定义 |
|------|------|
| 节点 Node | 时间轴上的一个时间点 + 该时刻要做的事 |
| 格 Cell | 节点占据的可视方块，按真实时长等比宽度 |
| 直条 Bar | 起床 → 入睡 的横向时间条，黄色系格子 |
| 睡觉弧 Arc | 入睡跨夜连回起床的蓝色弧线，代表夜晚 |
| 游标 Cursor | 当前时间在时间轴上的位置，实时移动 |
| 闭环 Loop | 直条（白天）+ 弧（夜晚）= 完整 24 小时，首尾相接 |

**关键设计**：闭环 24 小时时间轴。游标白天走直条、夜晚走弧，永不停止。

## 2. 时间精度：自适应递增（D1 + D10）

节点可设任意时间；显示精度随剩余时间自动升档。

**显示方式：动态数字式** —— 显示实际剩余时间，但措辞/样式按档位变化。

| 剩余时间 | 显示内容 | 视觉强度 |
|---------|---------|---------|
| > 2 小时 | `还有 4 小时`（动态数字） | 常规 |
| 30 分 ~ 2 小时 | `还有 1 小时 20 分`（动态数字） | 常规 |
| 10 ~ 30 分钟 | `还有 25 分钟`（动态数字） | 放大 1.2 倍，色温转暖 |
| ≤ 10 分钟 | **`还有最后 7 分钟`**（动态数字） | 1.6 倍 + 脉冲 + 变色 |
| ≤ 5 分钟 | **`还有最后 3 分钟`**（动态数字） | 2 倍 + 强脉冲 + 红橙 |
| ≤ 1 分钟 | **`还有最后 45 秒`**（动态数字） | 逐秒读数 |

**示例**：
- 剩余 7 分钟 → 「还有最后 **7** 分钟」（大字+脉冲）
- 剩余 30 秒 → 「还有最后 **30** 秒」
- 剩余 3 小时 → 「还有 **3** 小时」（常规字号）

- 档位阈值在家长面板可调（不写死）
- 最后阶段用「**还有最后 X 分钟**」措辞（用户原话），X 为实际剩余数字

### 3.1 一天结构

```
【起床 可设】→【中间活动 自定义】→【睡觉 可设】
```

## 4. 视觉与配色（D5 + D11）

### 4.1 颜色按类别编码（≤6 色，防视觉噪音）

| 类别 | 色系 | 色值 | 活动 |
|------|------|------|------|
| 进食 | 暖橙 | `#F59E0B` | 早饭、午饭、晚饭、点心 |
| 睡眠 | 冷蓝 | `#3B82F6` | 睡觉、午睡、起床 |
| 玩耍/自由 | 草绿 | `#22C55E` | 玩玩具、户外 |
| 卫生 | 青 | `#14B8A6` | 刷牙、洗澡、洗手 |
| 学习 | 紫 | `#A855F7` | 绘本、拼图、英语 |
| 外出 | 天蓝 | `#0EA5E9` | 上学、放学 |

### 4.2 必须做 vs 自由（边框区分，无角标）

| 类型 | 表现 |
|------|------|
| 必须做 | **实线粗边框**（3px）+ 图标饱满 |
| 自由 | **虚线边框**（2px dashed）+ 图标略淡 |

### 4.3 三态（过去/现在/未来）

| 状态 | 表现 |
|------|------|
| 已过去 | 去饱和 + 变灰 + 图标半透明 |
| 当前 | 原色 + 高亮描边 + 呼吸动画 |
| 未来 | 饱满原色 |

### 4.4 UI 原则

- ✅ 大色块、高对比、图标≥48px
- ✅ 不用深色模式
- ❌ 不用霓虹/渐变/发光
- ❌ 一屏颜色 ≤ 6 种

## 5. 提醒方式（D3 + D4）

| 项 | 规格 |
|----|------|
| 技术 | Web Audio `OscillatorNode`，代码生成，**零文件零依赖** |
| 音效 | 三短音「嘀-嘀-嘀」（1000Hz，每声 150ms，间隔 100ms） |
| 提前提醒 | 节点前 5 分钟轻响一次（单短音） |
| 节点提醒 | 节点整点三短音一次 |
| 关闭 | 家长面板开关，**每台设备独立** |
| 静音时段 | 睡觉弧内不响 |

## 7. 多设备同步与存储（D6）

### 7.1 架构

| 层 | 实现（Phase 1） |
|----|---------------|
| 存储 | `StorageAdapter` 接口，当前实现 `LanAdapter`（本机 JSON 文件） |
| 同步 | Node 服务 + SSE，配置变更实时推送所有设备 |
| 访问 | **共享访问口令**（非账号体系）—— 家长面板内可设，新设备首次访问需输入，验证后记住（localStorage） |
| 游标 | 各设备用本地系统时钟各自计算，不依赖网络 |

### 7.2 预留云端（将来若要外网访问）

`LanAdapter` → `CloudAdapter` 仅改一个文件。云端选型待定：
- **腾讯云开发 CloudBase**：若做微信小程序则选（天然打通）
- **Supabase**：仅做网页则选（接入最快）

### 7.3 关键洞察

挂钟模型下，时间游标各设备自算，**只需同步"配置"一份数据**，同步压力极小。

## 10. 边界条件清单

| # | 边界条件 | 处理 |
|---|---------|------|
| 1 | 跨夜（20:30 → 次日 07:30） | 闭环 wrap-around |
| 2 | 当前在睡觉弧上 | 游标沿弧移动，剩余 = 距起床 |
| 3 | 零点 rollover | 自动翻日，当日提醒记录清零 |
| 4 | 跨夜排序 | 归一化「距起床分钟数」再排 |
| 5 | 节点时间冲突 | 保存自动重排，冲突高亮 |
| 6 | 配置为空 | 兜底默认作息，不白屏 |
| 7 | 音频未激活 | 首次交互前显示「点一下开启声音」 |
| 8 | 多设备重复提醒 | 服务端按 (日期+节点ID+类型) 去重 |
| 9 | 页面后台节流 | 切回用 `Date.now()` 补算（复用漂移补偿） |
| 10 | 半小时间隔 | 内部统一用「分钟」存储，显示层换算 |
| 11 | 访问口令为空 | 若家长未设口令，则新设备免验证直接访问；口令为空 = 不启用认证 |
| 12 | 多设备口令同步 | 口令本身是配置的一部分，手机设了口令后 SSE 推送到平板；未设口令的设备不受影响 |
