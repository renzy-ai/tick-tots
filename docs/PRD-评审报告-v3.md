## 三、建议优化项详解

### 建议 #1：默认作息引导（低优先级）

**问题：** 默认作息是推测值，用户首次使用可能需要调整。

**建议：** 首次启动时显示引导提示：
```
欢迎使用！默认作息已为你设置好，
你可以长按左上角齿轮图标 2 秒，进入家长面板调整。
```

**影响：** 低（不影响核心功能）

---

### 建议 #2：拖拽交互细节（中优先级）

**问题：** §6 提到"拖拽节点左右移动"，但未定义细节：
- 拖拽时是否实时显示新时间？
- 松手后是否自动保存？
- 拖拽冲突（两个节点重叠）时怎么处理？

**建议：** 补充交互规格：

| 操作 | 交互 |
|------|------|
| 拖拽中 | 节点半透明，显示临时时间标签（如 "08:15"） |
| 松手 | 自动吸附到整点/半点，保存配置 |
| 冲突 | 自动重排，冲突节点短暂高亮 |

**影响：** 中（影响用户体验）

---

### 建议 #3：错误提示（低优先级）

**问题：** 网络断开、配置保存失败时，用户看不到反馈。

**建议：** 添加 toast 提示：
- 网络断开："网络连接已断开，配置将保存到本地"
- 保存失败："配置保存失败，请重试"

**影响：** 低（边缘场景）
