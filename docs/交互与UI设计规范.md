# TickTots 交互设计 + UI 设计规范

**版本**：v1.1  
**日期**：2026-09-01（v1.0 发布于 2026-08-28）  
**参考**：Tot Clock 项目视觉风格  
**适用对象**：学龄前儿童（2-6岁）

---

## 一、设计原则

### 1.1 核心理念

| 原则 | 说明 |
|------|------|
| **大色块、高对比** | 2-3岁不识字，靠颜色和形状区分 |
| **不依赖文字** | 所有关键信息用图标+颜色传达 |
| **直观时间流逝** | 灰色=已过去，原色=当前/未来 |
| **防误触** | 家长面板隐藏入口，儿童无法误操作 |

> **v1.1 修订说明（2026-09-01）**：实现阶段确认了三条与设计初衷不同、但实测更好的决策，规范反向对齐实现：
> 1. **视觉风格**：保留渐变背景 + 柔和投影 + 紧急态发光（原 v1.0 写的是"扁平无渐变"，实际渐变让色块更有层次、也更能吸引幼儿注意力）；
> 2. **进食 = 珊瑚橙、外出 = 暖黄**（原 v1.0 是反的）：珊瑚橙比暖黄更醒目，适合正餐；外出改暖黄后，也顺带解决了原规范"外出天蓝与睡眠冷蓝色相太近、分不清"的问题；
> 3. **增加睡觉夜间模式**（原 §1.2 "不用深色模式"与 §3.4 "睡觉模式深色夜空"自相矛盾）：以 §3.4 为准，睡觉时段主屏切深色，白天仍为亮色。

### 1.2 视觉风格

参考 Tot Clock 的大色块风格，在扁平基础上保留适度的纵深：

- ✅ 大色块 + **柔和渐变**（`linear-gradient(135deg, 浅 → 深)`），增强层次
- ✅ 圆角矩形（8 / 12 / 18px 三档，见 `theme.css` 的 `--r-*`），友好柔和
- ✅ 大图标（≥48px），易识别
- ✅ 一屏颜色 ≤ 6 种（靠「类别配色」保证，见 §2.1）
- ✅ 图标与文字加**柔和投影**，保证在任意活动底色上都读得清
- ⚠️ 发光效果仅限「剩余时间紧急态」（最后 5 分钟），日常不用
- ❌ 不用霓虹、高饱和撞色
- ❌ 白天不用深色模式（睡觉时段例外，见 §3.4）

## 二、颜色系统

### 2.1 按「类别」编码，不按单个活动

超过 6 种颜色就是视觉噪音。用颜色区分活动**类别**：

> 单一色值来源：`src/lib/theme.css`（CSS 变量）与 `src/lib/activities.ts` 的 `palette`（TS 侧）。**改色只改这两处**，两处需同步。

| 类别 | 色系 | 浅色（节点填充） | 深色（渐变末端） | 活动 |
|------|------|------|------|------|
| 进食 | 珊瑚橙 | `#F0997B` | `#D85A30` | 早饭、午饭、晚饭、点心 |
| 睡眠 | 冷蓝 | `#85B7EB` | `#378ADD` | 睡觉、午睡、起床 |
| 玩耍 | 草绿 | `#97C459` | `#639922` | 自由时间、户外、看动画 |
| 卫生/自理 | 青 | `#5DCAA5` | `#1D9E75` | 刷牙、洗澡、上厕所、收拾、穿衣服 |
| 学习 | 紫 | `#AFA9EC` | `#7F77DD` | 故事、念书、拼图、音乐、安静时间 |
| 外出 | 暖黄 | `#FAC775` | `#BA7517` | 去幼儿园、幼儿园、放学·接 |

**归类唯一入口**：`activities.ts` 的 `ACTIVITY_META`（每项带 `category`），新增活动只改这一处，颜色自动从 `palette` 取，禁止手写色值。

### 2.2 状态色

| 状态 | 色值 / 变量 | 用途 |
|------|------|------|
| 已过去 | `--track-past`（压暗 22%，不再铺灰） | 时间轴左侧已过区域。奶油底上比纯灰更清楚 |
| 当前 | 原色 + `--c-current` `#FF6B35` 描边 + 呼吸动画 | 正在进行的节点 |
| 放大提醒（≤10min） | `#FFF1E6` + 橙色柔光 | 阈值可调（`soonSeconds`） |
| 紧急（≤5min） | `--c-urgent` `#FF5A2B` + 强发光 + 脉冲 | 阈值可调（`urgentSeconds`） |
| 当前时间游标 | `--c-cursor` `#EF4444` | 直条/睡觉弧上的位置指针 |

**白天直条用中性奶油色 `--track-day` `#FFEFC2` + 白描边**，不用纯黄 `#FFD93D`：主背景会跟随当前活动变色，纯黄在黄/橙系活动（早饭、点心）上会与背景融掉。

### 2.3 边框区分

| 类型 | 边框样式 | 含义 |
|------|----------|------|
| 必须做的事 | **实线粗框**（3px） | 吃饭、刷牙、洗澡、睡觉 |
| 自由时间 | **虚线框**（2px dashed） | 绘本、玩耍、拼图 |

## 三、主界面交互设计

### 3.1 界面布局（从上到下）

```
┌─────────────────────────────────────┐
│ ⚙️（半透明齿轮，长按2秒进设置）     │
├─────────────────────────────────────┤
│         当前时间（大字）            │
│           10:25 上午                │
├─────────────────────────────────────┤
│                                     │
│  时间轴直条（起床 → 活动 → 睡觉）   │
│  [灰色已过去][当前节点][未来节点]    │
│                                     │
├─────────────────────────────────────┤
│     时间标签：7:30  12:00  20:30     │
├─────────────────────────────────────┤
│                                     │
│      还有 X 小时 X 分钟             │
│     （自适应精度显示）              │
│                                     │
├─────────────────────────────────────┤
│      下一个：🍽️ 午饭（12:00）       │
└─────────────────────────────────────┘
```

### 3.2 时间轴直条（核心视图）

**视觉元素：**

| 元素 | 形状 | 大小 | 位置 |
|------|------|------|------|
| 已过去区域 | 灰色矩形 | 高50px | 左端，宽度=已过时间占比 |
| 当前节点 | 大色块矩形 | 60×70px | 游标位置，高亮描边+呼吸动画 |
| 未来节点 | 中色块矩形 | 50×50px | 均匀分布 |
| 睡觉节点 | 蓝色大矩形 | 60×70px | 右端 |
| 游标箭头 | 倒三角 ▼ | 20×20px | 当前节点上方 |
| 时间标签 | 小字 | 11px | 时间轴下方 |

**节点渲染规则：**
- 节点大小按**真实时长等比**渲染（如幼儿园8小时占8格合并显示）
- 节点间距 = 时间间隔的视觉映射
- 当前节点比未来节点大 20%（视觉焦点）

**游标动画：**
- 每秒更新位置（`setInterval` + 漂移补偿）
- 游标颜色 = 当前节点类别色
- 游标箭头始终在节点上方

### 3.3 自适应精度显示

| 剩余时间 | 显示内容 | 样式 |
|----------|----------|------|
| > 2小时 | `还有 4 小时` | 18px 常规 |
| 30分~2小时 | `还有 1 小时 20 分` | 18px 常规 |
| 10~30分钟 | `还有 25 分钟` | 22px 放大，暖色 |
| **≤10分钟** | `还有最后 X 分钟` | **28px + 脉冲 + 红色** |
| **≤5分钟** | `还有最后 X 分钟` | **36px + 强脉冲 + 红橙** |
| ≤1分钟 | `还有 X 秒` | 逐秒倒数 |

**脉冲动画：**
```css
@keyframes pulse {
  0%, 100% { transform: scale(1); opacity: 1; }
  50% { transform: scale(1.05); opacity: 0.9; }
}
```

### 3.4 睡觉模式（蓝色弧）

当系统时间在「睡觉时间 → 起床时间」区间内，界面切换为睡觉模式。

> 这是 §1.2「白天不用深色模式」的唯一例外：睡前孩子盯着屏幕，亮蓝背景会越看越精神，所以睡觉时段整体转深色。

**视觉（已实现）：**
- 主屏背景：`linear-gradient(160deg, #1A1A2E → #16213E)`（token：`--night-bg-from` / `--night-bg-to`）
- 顶部高光层收敛到 7% 透明度（深色底上 28% 白高光会泛成脏雾）
- 辅助文字走夜间 token：`--night-text` `#E8EEFC` / `--night-dim`（不用纯白，刺眼）
- 蓝色胶囊弧：`--sleep-arc-from` `#6BB6FF` → `--sleep-arc-to` `#4A90E2`，夜间透明度由 0.3 提到 0.5
- 月亮🌙节点挂在弧底正中（`sleep-node`），激活态加深为 `#2F6FB5`
- 中间大字显示「已睡 X小时X分 · HH:MM 起床」——跨夜长时段不显示倒计时（无意义）

**弧形进度：**
- 弧线总长 = 睡觉时长
- 已睡部分 = 弧底右侧实色进度条（从右往左推进）
- 红色游标沿弧底移动，指向当前进度

**夜间反相**：刻度线、刻度标签、睡觉弧标签、tooltip 全部反相为浅色（深色底上原深蓝/棕色会看不见），见 `Timeline.svelte` 的 `.timeline.night` 段。

**与主题色联动**：`index.html` 的 `theme-color` 与 `manifest.json` 统一为 `#378ADD`（睡眠蓝）。

### 3.5 三态渲染规则

| 状态 | 判定条件 | 视觉表现 |
|------|----------|----------|
| 已过去 | 节点结束时间 < 当前时间 | 去饱和 + 灰色 + 50%透明 |
| 当前 | 节点开始时间 ≤ 当前时间 ≤ 结束时间 | 原色 + 3px高亮描边 + 呼吸动画 |
| 未来 | 节点开始时间 > 当前时间 | 饱满原色 + 2px边框 |

## 四、家长面板交互设计

### 4.1 入口

- **位置**：屏幕左上角 100×100px 区域
- **视觉引导**：半透明齿轮图标⚙️（透明度 20%）
- **手势**：长按 2 秒
- **反馈**：进入时震动一下（`navigator.vibrate(50)`）
- **防误触**：快速点击无效，必须长按

### 4.2 面板布局

```
┌─────────────────────────────────────┐
│  ⚙️ 家长设置                    ✕   │
├─────────────────────────────────────┤
│  🕐 作息时间                        │
│  [起床时间]      [睡觉时间]         │
├─────────────────────────────────────┤
│  📋 活动节点（拖拽排序）   [+添加]  │
│  ┌──────────────────────────────┐  │
│  │ ⋮⋮ 🛏️ 起床 [07:30] [必须]  │  │
│  │ ⋮⋮ 🍽️ 早饭 [08:00] [必须]  │  │
│  │ ⋮⋮ 🧸 玩耍 [09:00] [自由]  │  │
│  │ ⋮⋮ ...                      │  │
│  └──────────────────────────────┘  │
├─────────────────────────────────────┤
│  🔔 提醒设置                        │
│  蜂鸣提醒      [开关]               │
│  提前提醒（分钟）[5]                │
├─────────────────────────────────────┤
│  📱 多设备同步                      │
│  访问口令      [设置口令]           │
├─────────────────────────────────────┤
│  [重置默认]        [保存配置]       │
└─────────────────────────────────────┘
```

### 4.3 节点拖拽交互

**拖拽手势：**
1. 按住节点左侧 ⋮⋮ 图标 0.3秒 → 进入拖拽模式
2. 拖拽中：节点半透明（opacity 0.7），显示临时时间标签
3. 松手：自动吸附到最近的整点/半点（±5分钟阈值）
4. 微调模式：按住 Shift 键拖拽，关闭吸附，1分钟步长

**冲突处理：**
- 两个节点时间重叠时，自动重排（后节点顺延）
- 被挤的节点短暂高亮（0.5秒黄色闪烁）

**删除节点：**
- 长按节点 1秒 → 弹出删除确认
- 或：左滑节点 → 露出红色删除按钮

### 4.4 添加节点

点击「+ 添加节点」按钮，弹出选择面板：

```
┌─────────────────────────────────────┐
│  选择活动类型                   ✕   │
├─────────────────────────────────────┤
│  预设活动：                         │
│  🍽️吃饭  🦷刷牙  🛁洗澡  📚绘本   │
│  🧸玩耍  🛏️起床  🌙睡觉  🎒上学   │
│  🏠回家  👵姥姥接  🎨手工  🎵音乐  │
├─────────────────────────────────────┤
│  或自定义：                         │
│  [输入活动名称]                     │
│  [选择图标]                         │
│  [选择类别颜色]                     │
├─────────────────────────────────────┤
│  [取消]            [添加]           │
└─────────────────────────────────────┘
```

### 4.5 保存与同步

- **保存配置**：点击按钮，立即写入 localStorage + 服务端
- **自动同步**：保存后通过 SSE 推送到所有在线设备
- **冲突提示**：如果配置被其他设备更新过，显示「配置已同步」toast

## 五、提醒交互设计

### 5.1 蜂鸣提醒

**音频：**
- 使用 Web Audio API 生成蜂鸣声
- 节奏：「嘀-嘀-嘀」三短音（每个 200ms，间隔 100ms）
- 音高：A4（440Hz）
- 音量：50%（可调节）

**触发时机：**
1. 节点前 5 分钟（可配置）→ 一次蜂鸣
2. 节点到达时 → 三次蜂鸣

**开关控制：**
- 家长面板一键开关
- 每台设备独立控制（不同设备可以一个响一个不响）

### 5.2 视觉提醒

- 节点到达前 5 分钟：当前节点边框开始脉冲动画
- 节点到达时：全屏短暂闪烁（0.3秒，透明度从 1→0.8→1）

## 六、响应式适配

### 6.1 屏幕尺寸

| 设备 / 场景 | 判定 | 布局 |
|------|------|------|
| 手机竖屏 | 默认 | 单列：时间条 → 当前活动 → 时间轴（`max-height: 50vh`） |
| 平板竖屏 | 768–1024px | 同单列，字号用 `min(vw, 上限)` 自动放大 |
| 手机 / 平板横屏 | `(orientation: landscape) and (max-height: 860px)` | 左右分栏：当前活动 40% + 时间轴 60%，顶部时间条改为绝对定位 |
| 家长面板窄屏 | `max-width: 480px` | 节点行改两行网格：主信息行（拖拽/图标/时间/删除）+ 次要操作行（微调/时长/必须） |

> 横屏断点阈值 860px 覆盖了 iPad 横屏（高 768–834）。此前写的是 560px，只覆盖手机横屏，平板横屏会退回单列、时间轴被 50vh 压扁。

### 6.2 挂墙模式

- 全屏显示（隐藏浏览器地址栏）
- PWA 安装后自动全屏
- 旋转锁定：建议竖屏使用
- 亮度控制：软件层面 100% 亮度（Wake Lock 防息屏）

## 八、动效规范

### 8.1 呼吸动画（当前节点）

```css
@keyframes breathe {
  0%, 100% { transform: scale(1); }
  50% { transform: scale(1.02); }
}
/* 周期 3秒，无限循环 */
```

### 8.2 脉冲动画（最后阶段）

```css
@keyframes pulse {
  0%, 100% { transform: scale(1); opacity: 1; }
  50% { transform: scale(1.05); opacity: 0.9; }
}
/* 周期 2秒，无限循环 */
```

### 8.3 游标移动

- 每秒更新一次位置
- 使用 `transition: left 1s linear` 平滑移动
- 节点切换时，游标颜色渐变（`transition: fill 0.5s`）

## 九、可访问性

### 9.1 色彩对比

- 所有文字与背景对比度 ≥ 4.5:1（WCAG AA）
- 图标颜色不作为唯一信息载体（配合形状/边框）

### 9.2 触控区域

- 所有可点击元素 ≥ 48×48px
- 节点间距 ≥ 8px，防误触

### 9.3 减少动画

- ✅ 已实现：`theme.css` 全局 `@media (prefers-reduced-motion: reduce)`，关闭装饰性动画
- 开启后禁用呼吸/脉冲/浮动动画，只保留位置与数据变化
